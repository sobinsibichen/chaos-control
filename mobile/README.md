# LAST.PUFF React Native CLI scaffold

This folder contains the JavaScript-only React Native CLI architecture for the native LAST.PUFF app.

It preserves the current behavior model:
- auth persistence
- shared app state
- home logging
- social radar and chat
- control scheduling
- roast analytics
- profile pricing and logout

Native Android blockers are intentionally not implemented yet. The files under `src/native/` are placeholders for the future accessibility, overlay, and foreground monitoring modules.
